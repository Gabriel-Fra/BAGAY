# BAGAY
- An Event-Sourced Registry for Barangay Public Infrastructure

**BAGAY** is an event-sourced registry designed to track and preserve the complete history of barangay public infrastructure. Instead of overwriting an asset's previous status, BAGAY records every update as an immutable event, allowing its current state and historical records to be reconstructed at any time.

The system uses an **event-driven architecture** with **Node.js** and a **publish/subscribe event broker**. Events generated by residents and maintenance workers can be processed independently by different consumers, including a public dashboard, maintenance queue, and historical archive.

### Key Features

* Permanent identity for each public infrastructure asset
* Immutable event-based maintenance history
* Event-driven and decoupled architecture
* Public asset information through QR code scanning
* Maintenance queue for infrastructure issues
* Historical archive for auditability and record preservation
* State reconstruction through event replay

### Technologies

* Node.js
* Event-Driven Architecture
* Publish/Subscribe
* Event Sourcing
* QR Codes
* JavaScript

### Purpose

BAGAY aims to address the loss of barangay infrastructure records caused by paper-based logs, spreadsheets, and administrative turnovers. By preserving the complete history of public assets, the system can support better maintenance planning, transparency, and community resilience.

**Sustainable Development Goal:** SDG 11 – Sustainable Cities and Communities, particularly Target 11.b.
